# ダンスデモ（スイングステップ）

3Dキャラクターがダンスを踊るだけの、単体のデモページ。
ビルド不要・three.js は CDN 読み込みなので、`index.html` をブラウザで開けば動く。

## 触れるところ

| 操作 | できること |
|---|---|
| 再生 / 一時停止 | スペースキーでも切り替えられる |
| 1/4拍ずつ送る | ←→ キー（Shift 併用で1拍ずつ）。動きを一コマずつ確認する用 |
| 再生位置 | スライダーで好きな拍へ飛べる |
| 速さ | 0.05〜1.5倍。0.15倍まで落とせるのでスロー確認ができる |
| カメラ | 正面/斜め/真横/後ろ/俯瞰/あおり。画面ドラッグで自由回転、ホイールでズーム |
| キャラクター | 4種類＋「3人で踊らせる」 |
| 手の軌跡 | 肘の通り道を線で残す。腕の振りの形を見るとき用 |
| 縦ノリ | 拍に合わせた上下の揺れの ON/OFF |
| リズム音 | 138BPM のキック/クラップ/ハイハットを鳴らす（音源ファイルなし、その場で合成） |
| ポーズ確認 | 各ポーズで静止させて形だけ見る |

URL に `?beat=12.5` `?pose=openL` `?cam=side` `?char=1` `?panel=0` を付けると、
その状態で開く（スクリーンショット確認用）。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `dance.js` | **振り付けのデータ本体**。ポーズ集＋「何拍目にどのポーズへ行くか」の並び。ここだけ他のプロジェクトへ持っていけば同じ踊りが再現できる |
| `character.js` | キャラクターのモデル。プリミティブの組み合わせだけで作る低ポリ |
| `main.js` | デモページ側（シーン・カメラ・UI・リズム音）。振り付けデータには一切混ざっていない |
| `index.html` / `style.css` | 画面 |
| `tools/shot.js` `tools/check.js` | headless Chrome を CDP 直叩きして確認するための開発用スクリプト |

## 振り付けについて

TikTok で広く踊られている定番の振り（特定個人の創作ではない動き）を参考に、
「どういう動きか」だけを見て一から組み直したもの。参考にした動画の映像・人物・
見た目は一切使っていない。

構成（138BPM / 28拍 = 約12.2秒でループ）:

1. **導入（0〜4拍）** 立ち姿 → 手招き ×3 → 溜め → 足を大きく開いて構え
2. **主役の動き（4〜12拍）** 「斜め」と「ひねって払う」を1拍ごとに交互、途中で左右反転
3. **差し色（12〜16拍）** 前へ投げる → 真横に開く → 左右のスワイプ
4. **主役の動き2周目（16〜24拍）** 右から入って左へ
5. **締め（24〜28拍）** 大きな斜め2連 → 両腕をVに開いて止める → 収める

裏拍には必ず「構え（両こぶしを胸の前）」に戻るのがこの踊りの骨。
表拍で思いきり伸ばして裏拍で縮める、の繰り返しで跳ねる感じを出している。

## 骨格について

`character.js` の骨格は「放課後の居残り」の `person()` と同じ寸法だが、
踊り用に関節を増やしてある。

```
root
 └ hips ─┬ legL → kneeL → ankleL
         ├ legR → kneeR → ankleR
         └ spine → chest ─┬ armL → elbowL → handL
                          ├ armR → elbowR → handR
                          └ neck → head
```

- 左右の呼び方は `person()` を踏襲。**L = -X（画面の左）／R = +X（画面の右）**、正面は +Z
- `dance.js` は「無い関節は黙って無視する」ので、肘や膝が無い簡易な骨格にもそのまま流せる
- 足が床にちょうど着くように毎フレーム root の高さを自動補正している（`danceApply` の `groundLock`）ので、ポーズごとに沈み込みの深さを手計算しなくていい
